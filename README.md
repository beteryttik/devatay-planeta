# Девятая планета: Сбой памяти (Ninth Planet: Memory Glitch)

Мод для Fabric 1.21.1. Сгенерированный каркас проекта — стартовая точка, не финальный мод.

## Что внутри
- **Цикл портала** (вариант 2): каждые 15 мин окно на 3 мин у обелиска, химеры-стражи защищают портал.
- **Оборона базы**: уязвимость растёт -> волны химер -> альфа-химера. Стены/двери/бункер с прочностью.
- **Химеры**: био-узлы (как на арте) + паразитированная техника (вертолёт, машина). Слабая точка — голова (x2 урон).
- **NPC**: женщины и мужчины, отбиваются от химер плазменными пушками, озвучка = твои .ogg файлы.
- **Панацея**: лечит всё, но даёт нестабильность (химеры слышат тебя дальше).
- **Воспоминания**: оверлей «прошлого мира», застывшие контейнеры с панацеей.
- **Небо**: две луны и два солнца.

## Быстрый старт
1. JDK 21, IntelliJ IDEA.
2. Добавь Gradle Wrapper (`gradle wrapper` или скопируй из fabric-template).
3. `./gradlew build` — JAR в `build/libs/`.
4. Читай `docs/ARCHITECTURE.md` и `docs/ROADMAP.md`.

## Важно
- Часть классов — заготовки с TODO (варианты химер, оружие, квесты).
- Код может требовать правок под актуальные Yarn-маппинги.
- Звуки (.ogg) добавляй сам — см. docs/AUDIO_HOWTO.md. Не коммить большие файлы.
- Текстуры — сгенерированные заглушки 16x16, замени на свои.

## Дерево проекта
- `src/main/java/com/ninthplanet/` — код по пакетам (core, chimaera, npc, base, portal, panacea, memory, sky, ui)
- `src/main/resources/assets/` — модели, текстуры, звуки, диалоги
- `src/main/resources/data/` — рецепты, лут, спавны, структуры, волны, события
- `docs/` — документация механик
- `.github/workflows/build.yml` — CI-сборка
