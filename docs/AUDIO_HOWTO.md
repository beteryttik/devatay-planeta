# Звуки NPC (голоса)
Положи свои записи (реальные голоса, мужчины и женщины) в:
`src/main/resources/assets/ninthplanet/sounds/npc/<профиль>/<фраза>.ogg`

Профили: engineer_male, medic_female, guard_male, scientist_female, commander_male.
Фразы: greeting, alert, panic, give_panacea, defend, wave_over, idle_01..03, quest_01..02,
portal_ready, obey, refuse, thanks, low_hp, healed, patrol, night, storm.

Формат: OGG Vorbis, моно, 22-44 кГц, до 3-5 секунд.
Не коммить большие аудиофайлы в git — залей в Releases и добавь ссылку в README.
