# Сборка

1. Установи JDK 21.
2. `gradle wrapper` (или добавь wrapper-файлы из шаблона Fabric).
3. `./gradlew build` — JAR в build/libs.
4. В IntelliJ IDEA: открыть проект, дождаться индексации Loom.

⚠️ Код — каркас: часть методов с TODO, некоторые вызовы могут отличаться в актуальных Yarn-маппингах 1.21.1 — правь по подсказкам IDE.
