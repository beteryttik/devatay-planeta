# Оборона базы

Уязвимость растёт: +5/мин простоя, бонусы за слабые места, заражение (x1.5), паника (+40).
Порог 100 -> волна:
1) Предупреждение 30-60 сек (блок тревоги мигает).
2) Волна 1: 3-5 химер, бьют слабые места.
3) Если прочность < 30%: волна 2 (6-8, таранщики).
4) Если < 10%: альфа-химера к сундукам.
После волны уязвимость сбрасывается, прочность надо чинить.
