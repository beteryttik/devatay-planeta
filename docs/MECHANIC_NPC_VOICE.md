# NPC с голосами

Голос = заранее записанные .ogg (реальные голоса людей, мужские и женские). Кладёшь файлы в
`assets/ninthplanet/sounds/npc/<профиль>/<фраза>.ogg`, названия совпадают с sounds.json.
Тексты реплик: `assets/ninthplanet/dialogues/profiles/<профиль>.json`.

Внешний ИИ для диалогов — НЕ внутри мода: это отдельный сервис/скрипт, мод лишь отображает ответ. Внутри мода — заготовленные реплики из JSON.
